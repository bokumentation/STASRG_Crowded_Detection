Petunjuk Penggunaan Aplikasi Crowded Detection

1. Versi Aplikasi Aktif

📐

Penentuan Mode Penghitungan

Aplikasi ini berjalan dalam dua mode utama yang ditentukan di file config.json:

  • → Versi Vertikal: Garis penghitung adalah **Vertikal**. Digunakan untuk mendeteksi pergerakan **Horizontal (kiri-kanan)**.
  • ↓ Versi Horizontal: Garis penghitung adalah **Horizontal**. Digunakan untuk mendeteksi pergerakan **Vertikal (atas-bawah)**.

2. Menu Utama (Index)

🔴

Live Video Feed & Hitungan

Menampilkan hasil deteksi objek (kotak batas) dan garis penghitung secara *real-time*. Hitungan **ENTRY**, **EXIT**, dan **CURRENT** (saat ini) diperbarui setiap detik.

🎥

Tombol 'Mulai/Stop Rekam'

Digunakan untuk merekam *live video feed* yang telah diberi anotasi (kotak batas, garis, hitungan, timestamp) ke file MP4 di folder output.

🔄

Tombol 'Reset Hitungan'

Mengatur ulang hitungan ENTRY, EXIT, dan menghapus seluruh riwayat data grafik ke nilai awal (biasanya 0).

📊

Tombol 'Unduh Data'

Mengunduh data hitungan historis (Timestamp, Entry, Exit, Current) ke file Excel (.xlsx) untuk analisis lebih lanjut.

3. Halaman Konfigurasi

⚙️

Penyesuaian Parameter Aplikasi

Gunakan halaman ini untuk mengubah: **Versi**, **Posisi Garis** (Entry/Exit), **Arah Hitungan (Swap Direction)**, **Resolusi Video**, dan nilai hitungan awal.

PENTING: Setiap perubahan konfigurasi yang disimpan memerlukan **RESTART APLIKASI** agar diterapkan sepenuhnya.
