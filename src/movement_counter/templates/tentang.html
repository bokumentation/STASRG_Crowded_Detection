Tentang Aplikasi Crowded Detection

1. Tujuan Utama

Aplikasi ini dirancang untuk memantau dan menghitung jumlah orang secara *real-time* di suatu area. Dengan memanfaatkan teknologi Computer Vision, aplikasi ini dapat memberikan data akurat mengenai jumlah orang yang masuk (Entry), keluar (Exit), dan jumlah total orang yang saat ini berada di dalam area (Current Count).

2. Teknologi

🧠

YOLOv8 (You Only Look Once)

Model jaringan saraf konvolusional (CNN) modern yang digunakan untuk mendeteksi objek (orang) secara akurat dan berkecepatan tinggi pada setiap frame video. Model ini adalah inti dari kemampuan hitungan orang (headcounting) aplikasi.

🐍

Python & Flask

Python sebagai bahasa utama dan Flask sebagai kerangka kerja web (backend). Digunakan untuk menyediakan API untuk streaming video (Motion JPEG) dan antarmuka web untuk konfigurasi/data.

📸

OpenCV

Pustaka utama yang menangani pemrosesan frame video, pengubahan ukuran, penambahan anotasi (kotak batas, garis virtual, teks penghitungan), dan manajemen kamera/video file.

🎯

Centroid Tracker

Algoritma pelacakan kustom yang digunakan untuk menjaga identitas objek (ID) antar frame. Hal ini penting untuk memastikan penghitungan orang yang konsisten saat mereka melintasi garis virtual.

🎨

Tailwind CSS

Digunakan untuk membangun antarmuka web yang responsif dan modern, memastikan tampilan yang konsisten dan menarik di berbagai perangkat.

3. Fitur Utama

  • Dua Mode Penghitungan: **Vertikal** (untuk pergerakan Horizontal) dan **Horizontal** (untuk pergerakan Vertikal).
  • Perekaman Video *On-Demand* dengan anotasi.
  • Ekspor data historis ke file Excel (.xlsx).
  • Konfigurasi dinamis garis penghitung, resolusi, dan arah hitungan.
