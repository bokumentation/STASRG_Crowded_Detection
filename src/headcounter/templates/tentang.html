Tentang Aplikasi Deteksi Kerumunan (Crowded Detection)

Aplikasi Crowded Detection adalah sistem real-time yang dirancang untuk memantau jumlah orang dalam suatu area menggunakan visi komputer. Sistem ini memberikan informasi status keramaian secara instan dan dapat dikonfigurasi untuk memicu peringatan jika batas kepadatan terlampaui.

Teknologi

🧠

YOLOv8 (You Only Look Once)

Model jaringan saraf konvolusional (CNN) yang digunakan untuk mendeteksi objek (orang) secara akurat dan berkecepatan tinggi pada setiap frame video. Model ini adalah inti dari kemampuan hitungan orang (headcounting) aplikasi.

💻

OpenCV (Open Source Computer Vision Library)

Digunakan untuk menangani input video dari kamera (Webcam), memproses frame, serta menggambar visualisasi seperti *bounding box* dan ID pelacakan (tracking IDs).

🌐

Python & Flask

Python adalah bahasa pemrograman utama. Flask adalah kerangka kerja (framework) web mikro yang digunakan untuk menyajikan video stream secara *real-time* dan menyediakan API untuk data hitungan serta konfigurasi.

📈

Pelacakan Centroid & Data Persistence

Sistem menggunakan algoritma pelacakan berbasis centroid untuk memastikan setiap orang dihitung sekali dan meminimalkan hitungan ganda. Data historis pengunjung disimpan dan dapat diekspor ke format Excel (`.xlsx`) untuk analisis lebih lanjut.

Versi dan Fitur Utama

  • Versi Aktif: Headcounter (Fokus pada hitungan orang dalam frame kamera dan status keramaian).
  • Deteksi dan pelacakan orang waktu nyata.
  • Pembaruan status keramaian secara otomatis ("Normal" atau "Padat").
  • Halaman konfigurasi untuk mengatur batas (trigger) keramaian.
  • Ekspor data pengunjung ke Excel.
