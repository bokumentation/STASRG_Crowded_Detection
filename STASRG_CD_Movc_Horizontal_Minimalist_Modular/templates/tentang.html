Tentang Sistem Deteksi Kerumunan

Teknologi Utama

  • **Inti Visi Komputer:** Menggunakan **YOLOv8 (You Only Look Once)** terbaru untuk deteksi objek real-time dengan akurasi tinggi.
  • **Pelacakan:** Menggunakan algoritma **Centroid Tracker** untuk mempertahankan ID unik objek yang bergerak dan mengatasi oklusi sesaat.
  • **Framework Backend:** Dibangun di atas **Flask** (Python) untuk menyajikan API dan *live video streaming* (M-JPEG).
  • **Antarmuka:** Menggunakan **Tailwind CSS** untuk desain *responsive* dan modern.

Pengembang

Aplikasi ini dikembangkan sebagai solusi untuk pemantauan kepadatan dan arah pergerakan pengunjung di lingkungan tertutup.
