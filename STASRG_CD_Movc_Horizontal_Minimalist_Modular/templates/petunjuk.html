Petunjuk Penggunaan Sistem

1. Memilih Mode Deteksi

Sistem ini mendukung dua mode penghitungan yang diatur melalui file config.json:

  • **Mode Horizontal:** Garis diatur secara horizontal (sumbu Y). Digunakan untuk menghitung gerakan Vertikal (naik/turun).
  • **Mode Vertikal:** Garis diatur secara vertikal (sumbu X). Digunakan untuk menghitung gerakan Horizontal (kiri/kanan).

2. Fungsionalitas Dashboard

  • **Live Video:** Menampilkan hasil deteksi real-time (Bounding Box dan Garis) dengan Overlay Timestamp.
  • **Current's Visitor:** Menampilkan total pengunjung saat ini (Masuk - Keluar).
  • **Tombol Merekam:** Gunakan tombol **Mulai Merekam** untuk menyimpan video output (termasuk deteksi) ke folder /recordings. File akan otomatis dinamai dengan waktu dan versi (Vertical/Horizontal).
  • **Download Excel:** Mengunduh data historis hitungan (perubahan hitungan) ke dalam file Excel untuk audit.
  • **Reset Hitungan:** Mengatur ulang semua total hitungan (Masuk, Keluar, Saat Ini) ke nol.

3. Optimasi (Troubleshooting)

Untuk performa terbaik, pastikan spesifikasi perangkat keras (CPU/GPU) Anda memadai. Jika FPS terasa lambat, coba:

  • Kurangi resolusi frame (resize.width/height) di config.json.
  • Tingkatkan nilai max_disappeared untuk membuat pelacakan lebih toleran terhadap kegagalan deteksi sesaat.
